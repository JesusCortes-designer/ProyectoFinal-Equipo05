# Colección Bruno - Terminal de autobuses (Equipo 05)

1. Abre Bruno > Open Collection > selecciona esta carpeta.
2. Arriba a la derecha elige el ambiente `local` (o `vps` y cambia la url por tu dominio).
3. Con el backend corriendo, dale **Run** a la colección completa. Las carpetas van en orden
   (00 a 09) porque guardan tokens e ids en variables para las siguientes peticiones.

Usuarios de prueba: admin@terminal.com / taquillero@terminal.com / cliente@terminal.com (contraseñas en el ambiente).
Las reservaciones se hacen con un cliente nuevo de teléfono falso para no gastar SMS/WhatsApp reales.
